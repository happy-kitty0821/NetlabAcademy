# Product steering — NetLab Academy

- This is an independent networking education platform for CCNA/CCNP learning, examinations and practical network simulation.
- Primary roles are platform administrator, instructor and student.
- The platform combines a Boson ExSim-inspired assessment experience with an original Packet Tracer-inspired educational topology workspace.
- The simulator is an original software model. It does not run Cisco IOS or claim to be Cisco Packet Tracer.
- Prioritize accuracy, reproducibility, secure isolation and learning outcomes over feature breadth.
- Build in vertical slices and use Kiro feature specs (`requirements.md`, `design.md`, `tasks.md`) for meaningful work.
- Never copy proprietary question banks, images, software assets or device images without appropriate rights.
- Read `PROJECT_SPEC.md` before making material product or architecture decisions.
